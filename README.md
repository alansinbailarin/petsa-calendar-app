### Bienvenido!

Este repositorio es la respuesta en cuando al reto de PETSA, en el cual se encontraran algunas modificaciones en el backend y el nuevo proyecto en frontend hecho en Vue 3 Composition API con Typescript, para completar este reto, se creo un monorepo con el repositorio previamente creado del reto, esto para hacer todo de la manera mas sencilla.

### Arrancar proyecto

- Tener Git instalado
- Tener Docker instalado
- Clonar el repositorio
- Entrar a entry-calendar-app
- docker compose up --build

Esto deberia de correr todos los servicios necesarios (backend y frontend).
Frontend → http://localhost:5173
API → http://localhost:65432
